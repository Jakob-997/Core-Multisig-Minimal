POST-CREATION GUIDE

Your M-N Bitcoin Core multisig wallet has been created.

You can reopen this guide at any time from the project folder as:
POST-CREATION-GUIDE.txt

The "multisig-backups" folder in the same directory as this guide contains one
folder for each signer and one watch-only wallet.

Keep this computer and all backup media attended for the rest of this process.

1. Burn each signer folder and the watch-only folder to its matching labeled CD-R.

   Brasero is included with Tails and can burn these wallet folders as ordinary
   data discs.

   For each wallet folder:

   - Open Brasero and choose "Data Project".
   - Click the + / Add button and add exactly one wallet folder, such as signer_1.
   - Make sure the project contains the correct wallet folder for the disc you
     labeled.
   - Insert the matching blank CD-R.
   - Click "Burn" and select the optical drive.
   - Do not choose "Burn image". These are ordinary folders, not ISO images.
   - When the burn finishes, eject and reinsert the disc and confirm that the
     wallet folder and its wallet.dat file can be opened and read.

   Repeat this separately for every signer folder and for the watch_only folder,
   using one labeled CD-R per wallet folder.

2. Verify every CD-R can be read and every wallet loads correctly.

   A CD-R is read-only. When testing a backup, first copy the wallet folder from
   the disc to a temporary writable location on the offline Tails session, then
   load that copied wallet in Bitcoin Core. Do not try to run the wallet database
   directly from the CD-R.

3. Confirm every signer wallet and the watch-only wallet derive the same multisig
   receive addresses.

   For this workflow, the verified offline signer computer is the source of truth.
   Do not rely on an online computer alone to tell you that a receive address is
   correct.

   Before sending bitcoin to any receive address shown on the online computer,
   independently verify that the same address is derived by an offline signer.

4. Take ONLY the WATCH ONLY disc to your online computer.

   Copy the watch_only folder from the CD-R to writable storage on your fully
   synced online Bitcoin Core computer, then load that copied wallet. The node may
   be pruned, but it must still have every block Core needs to synchronize this
   wallet. If Core reports that the required history has already been pruned,
   reindex/redownload or use a node with the missing block history. Use this wallet
   to monitor the multisig and to create unsigned transactions/PSBTs.

   NEVER put a signer disc into the online computer.

5. Do a disposable test spend.

   Send a small amount of bitcoin to a receive address that you have independently
   verified on the offline signer.

   You can perform the test spend entirely through the Bitcoin Core GUI:

   - On the ONLINE computer, open Bitcoin-Qt and select the watch_only wallet.
   - Open the Send tab, enter the destination and small test amount, review the
     fee and transaction details, then choose "Create Unsigned".
   - Save the unsigned PSBT to a file and transfer that file to the OFFLINE
     computer. Keep an unchanged copy of this original unsigned PSBT for testing
     additional signer backups.
   - On the OFFLINE computer, open Bitcoin-Qt and load one signer wallet from a
     writable copy of its CD-R backup.
   - In Bitcoin-Qt choose "Load PSBT from file...", open the PSBT, independently
     verify the destination address, amount, fee, and transaction details, then
     click "Sign Tx".
   - Click "Save..." and save the resulting partially signed PSBT.
   - Load the next signer wallet, open the newly saved PSBT with "Load PSBT from
     file...", verify it again, click "Sign Tx", and save it again.
   - Continue until M valid signer wallets have signed and Bitcoin Core reports
     that the transaction is complete.
   - Transfer the completed PSBT back to the ONLINE computer, load it in
     Bitcoin-Qt, verify the transaction again, and broadcast it.

   To test every one of N signer backups when N is greater than M, do not rely on
   adding every signature to the same PSBT after the threshold has already been
   reached. Start again from the unchanged original unsigned PSBT for any signer
   that was not part of the completed M-of-N path, confirm that signer can add a
   signature, and save/check the result. This verifies every signer backup while
   separately confirming that the intended M-of-N threshold completes a spend.

   NEVER approve a transaction from the online computer's display alone. The
   destination address, amount, fee, and transaction details must be checked on
   the OFFLINE computer before each signature.

ONLINE COMPUTER IS UNTRUSTED

Treat the online computer as potentially compromised. Malware on an online machine
can change what appears on the screen, substitute addresses, alter transaction
details, or make a malicious transaction look legitimate.

For transaction approval, trust the verified offline signer display, not the online
computer:

- Verify receive addresses with an offline signer before sending bitcoin to them.
- Verify destination addresses and amounts on the offline computer before signing.
- Never place a signer CD-R in an online computer.
- Never sign a transaction merely because the online computer says it is correct.

6. Once every CD-R has been verified and the test spend succeeds, immediately
   shut the offline computer down and remove the Tails USB.

7. Put each labeled CD-R in a protective, durable case and take it directly to
   its intended storage location.

The signer wallets are not encrypted. Anyone with a signer disc can copy that
signer's private key. Anyone with any of the wallet discs can derive the wallet's
addresses and monitor its on-chain activity. Do not leave the computer or backup
discs unattended at any point during this process.

Finished. You can now close this guide.
